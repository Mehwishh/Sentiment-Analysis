#Sentiment Analysis# Sentiment Analysis

A machine learning-based NLP project that classifies text sentiment using TF-IDF and a supervised machine learning model.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK
- Joblib
- Jupyter Notebook
